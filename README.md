# Tic-Tac-Toe (Beginner Friendly)

This is a very small browser game you can run locally with no setup.

## Run it

1. Open this folder.
2. Double-click `index.html`.
3. Your browser will open the game.

## How to play

- Player **X** goes first.
- Players take turns clicking a square.
- The first player to get 3 in a row wins.
- Click **Start New Game** to play again.

## Files

- `index.html` — the page structure
- `styles.css` — the colors/layout
- `script.js` — the game rules and button behavior
